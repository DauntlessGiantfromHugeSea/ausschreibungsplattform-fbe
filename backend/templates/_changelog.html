{# Zentrale Update-/Changelog-Liste. Neue Versionen oben einfuegen. #}
  1. v0.10.0 2026-06-19 Anhang-Manager & Hochleistungs-Bot
    • Vollstaendige Anhang-Erfassung: Enricher-Bot sammelt jetzt alle verlinkten Vergabeunterlagen pro Ausschreibung (PDF, DOCX, XLSX, ZIP), speichert sie in /srv/fbe-attachments/<id>/ und meldet Metadaten an die Plattform.
    • Anhang-Block auf der Detail-Seite: Liste aller gefundenen Dateien mit Name, Groesse und direktem Download-Link — ohne erneuten Portal-Login.
    • Login-tiefe Crawls: Wenn fuer ein Portal Zugangsdaten unter Portal-Logins hinterlegt sind, sieht der Bot auch geschuetzte PDFs und Vergabeunterlagen.
    • Limits konfigurierbar: MAX_ATTACHMENTS, MAX_ATTACHMENT_MB, ATTACHMENT_EXTENSIONS per Enricher-.env.
  2. v0.9.0 2026-06-19 Design-Refresh & Claude-Analyse
    • Komplettes UI-Refresh: Dunkles Teal-Navigation (#003233) + Lime-CTAs (#d4f561) + Liquid-Glass-Cards, identisch zum FBA-Schwester-Tool.
    • Split-Login-Screen: Markenpanel links mit Headline „Tiefbau. Verfuellung. Fluessigboden." + weisses Formular rechts mit Pill-Button.
    • Neues SVG-Logo (skalierbar) plus aktualisierte Mail-Templates in Teal.
    • Tiefe Claude-Analyse: Per Knopfdruck auf der Detail-Seite eine strukturierte FBE-Bewertung mit Einsparungspotenzial + Fluessigboden-Eignung — nutzt Anthropic Claude (Modell konfigurierbar, default claude-sonnet-4-6).
    • Portal-Logins per UI: Zugangsdaten + Selektoren pro Portal im Admin-Bereich pflegbar, mit „Jetzt testen"-Button und Live-Status. Dropdown fuer Auto-Fill aus portals.yaml.
    • Notes & Wissensbasis: Obsidian-artiger Markdown-Editor unter Einstellungen, fliesst automatisch in den Enricher-Prompt.
    • Profilgebundene User: Neue Rolle user sieht nur Ausschreibungen aus zugewiesenen Suchprofilen; Rolle viewer sieht alles ohne Admin-Bereich; admin wie bisher.
    • Neue Quellen: bund.de RSS-Feed, greenprofi.de (Tiefbau-Kategorien), vergabeportal-bw.de (Cosinex Satellite), DB Bieterportal (HH eVergabe), myFUTURA-Sourcing.
  3. v0.6.0 2026-05-19 KI-Assistent & Tender-Analyse
    • KI-Analyse pro Ausschreibung: Auf jeder Detailseite wird automatisch eine Bewertung erzeugt - FBE-Eignung (hoch/mittel/gering), 2-4 Stichpunkte und eine geschaetzte Kostenersparnis durch Fluessigboden in Prozent + EUR-Bandbreite. Ergebnis wird gespeichert und nur per Klick "Neu analysieren" aktualisiert.
    • Globaler Assistent: Sparkles-Icon oben rechts oeffnet einen vollwertigen Chat mit dem FBE-Wissen im Kontext.
    • Schnellfrage in der Hilfe: Auf der Hilfe-Seite ein Eingabefeld fuer einzelne Fragen ohne Chat-Verlauf.
    • Editierbare Wissensbasis: Unter Einstellungen → KI-Wissensbasis kann jeder Admin den Kontext fuer die KI pflegen (Markdown). Aenderungen wirken sofort.
    • Modell: OpenAI gpt-4o-mini als Default (guenstig, schnell), Modell und API-Key via .env konfigurierbar.
  4. v0.5.0 2026-05-19 Persoenliche Benachrichtigungen
    • Eigene Zusammenfassungen: Jeder Nutzer kann ueber das User-Menue → "Meine Benachrichtigungen" eine taegliche oder woechentliche Mail mit den relevantesten Ausschreibungen aktivieren.
    • Score-Schwelle frei waehlbar (0-100): Nur Treffer ab diesem Wert kommen in die Mail.
    • Mail-Adresse pro User wird beim Speichern uebernommen; ohne Adresse keine Benachrichtigung.
    • Test-Mail-Knopf direkt auf der Einstellungsseite, um sofort eine Beispiel-Zusammenfassung zu erhalten.
    • Scheduler prueft taeglich frueh, welche Nutzer faellig sind (daily ≈ alle 24 Std., weekly ≈ alle 7 Tage).
  5. v0.4.0 2026-05-19 Verlauf, Broadcast & UI-Aufraeumen
    • Verlauf pro Ausschreibung: Wer hat den Status wann geaendert, an wen wurde gemailt - alles in einer Timeline auf der Detailseite.
    • Broadcast-Mail: Admins koennen unter Einstellungen → Broadcast eine Mail an alle aktiven Nutzer schicken (BCC, Adressen untereinander unsichtbar).
    • Erst-Login mit eigenem Passwort: Neue User bekommen Einladungs-Mail mit Link, setzen ihr Passwort selbst (24 Std. gueltig).
    • Passwort vergessen: Reset-Link kommt jetzt wirklich per Mail (1 Std. gueltig) - die Routen hatten vorher gefehlt.
    • Top-Menue minimal: Nur noch Dashboard und Profile sichtbar, der Rest hinter Icons - Ampel fuer Status/Probe, Zahnrad fuer Einstellungen, Fragezeichen fuer diese Hilfe.
    • Linke Sidebar auf Einstellungen- und Hilfe-Seiten mit allen Unterpunkten.
    • Hilfe-Seite unter /hilfe mit Doku zu allen Funktionen und diesem Update-Verlauf.
