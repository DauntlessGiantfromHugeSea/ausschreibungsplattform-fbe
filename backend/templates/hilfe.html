Hilfe & Dokumentation

Übersicht

Die Flüssigboden Akademie · Ausschreibungen durchsucht regelmäßig die konfigurierten Vergabeportale nach passenden Ausschreibungen, filtert sie anhand der hinterlegten Suchbegriffe und Profile und stellt die Treffer im Dashboard bereit. Über die Top-Leiste erreichst du jederzeit Dashboard, Profile, System-Status (🚦), Einstellungen (⚙️) und diese Hilfe (❓).

Dashboard & Suche

  • Suche starten: Knopf oben rechts stößt einen sofortigen Scan aller aktivierten Portale an.
  • Filter: Über die Chips und Suchfelder lassen sich Treffer nach Status, Portal, Zeitraum oder Stichwort eingrenzen.
  • Detailansicht: Klick auf eine Ausschreibung öffnet alle Felder, Anhänge und ermöglicht Kommentare sowie Statuswechsel.

Profile

Profile bündeln einen Satz Suchbegriffe und Portal-Auswahl. Wendet man ein Profil an, wird das Dashboard automatisch danach gefiltert. So lassen sich verschiedene Themengebiete oder Kunden sauber trennen.

Portale verwalten

  • Einstellungen → Portale: Liste aller konfigurierten Portale, mit Schalter zum Aktivieren/Deaktivieren.
  • Neue Portale werden über die YAML-Definition (config/portals.yaml) oder den Editor angelegt.
  • Vor dem Scharfschalten Portal mit der Probe (🚦 → Probe) testen.

Suchbegriffe

Globale Suchbegriffe gelten für alle Portale. Sie können Synonyme, Ausschlüsse und Gewichtungen enthalten. Über die Profile lassen sich zusätzlich eigene Begriffslisten pflegen.

Status & Probe

  • 🚦 Status: Letzte Läufe pro Portal, Trefferzahlen, Fehler, Sperren.
  • Probe: Einzelnes Portal testweise abfragen, ohne Datenbank-Änderung.
  • Alle testen: Schneller Funktionstest aller Portale auf einmal.

Benutzer

Unter Einstellungen → Benutzer lassen sich Konten anlegen, Rollen vergeben (Admin / Viewer / User) und Passwörter zurücksetzen. Neue Benutzer bekommen per E-Mail einen Link zum Vergeben des eigenen Passworts.

  • admin — voller Zugriff auf alle Admin-Bereiche.
  • viewer — sieht alle Ausschreibungen + Suche, aber kein Admin-Bereich.
  • user — sieht ausschließlich Ausschreibungen aus zugewiesenen Suchprofilen, keine freie Suche.

Portal-Logins (KI-Anreicherung)

Für Portale, deren Detailseiten nur nach Login sichtbar sind (z.B. evergabe.de, DTVP), kann der KI-Bot sich automatisch einloggen. Die Zugangsdaten werden ausschließlich im Admin-UI gepflegt — kein Server-Zugang nötig. Andere Admins können die Zugänge nachträglich anpassen, ohne die .env auf dem Server zu kennen.

  1. Einstellungen → Portal-Logins → + Neuer Login
  2. Host: nur die Domain ohne https:// — z.B. evergabe.de
  3. Login-URL: die Adresse der Login-Seite — z.B. https://www.evergabe.de/login
  4. Benutzername / Passwort: deine Login-Daten für dieses Portal. Wird in der lokalen DB gespeichert; im Edit-Modus zeigt das Passwortfeld nie das gespeicherte Passwort, leer lassen = unverändert.
  5. CSS-Selektoren: zeigen dem Bot, wo das Username-Feld, das Passwort-Feld und der Login-Button sind.
    • Login-Seite im Browser öffnen, F12 drücken (DevTools).
    • Rechtsklick auf das Benutzername-Feld → Untersuchen. Im HTML siehst du etwas wie <input name="user[email]"> → der Selektor ist input[name='user[email]'].
    • Gleiches für Passwort-Feld und Submit-Button.
  6. Erfolgs-Selektor (optional): ein Element, das nur eingeloggt vorhanden ist (z.B. a[href*='logout']) — der Bot weiß damit, ob der Login geklappt hat.

In der Übersicht zeigt eine farbige Pille pro Portal den letzten Login-Status: ✓ ok, ✕ fail (Mouse-Over zeigt den Fehlergrund) oder noch nicht versucht. Der Enricher-Bot pollt die Login-Liste alle 60 Sekunden und versucht beim nächsten Tender-Crawl automatisch den Login.

Notizen & KI-Wissensbasis

Unter Einstellungen → Notizen & Wissen kannst du Markdown-Dateien anlegen und bearbeiten:

  • Wissensbasis — alles hier wird als zusätzlicher Kontext an den KI-Bot übergeben. Schreib hier rein, was das LLM über deine Firma / die relevanten Themen wissen soll.
  • Tender-Anreicherungen — die fertigen KI-Auswertungen pro Tender. Direkt im UI editierbar.

Tastenkürzel im Editor: Strg+S speichert. Oben rechts: Edit / Split / Vorschau-Modi.

KI-Anreicherungen

Der separate Enricher-Container öffnet alle 10 Minuten neue Tender, klickt sich durch ihre Detailseiten, lädt verlinkte PDFs und erstellt mit OpenAI eine strukturierte Markdown-Zusammenfassung pro Tender. Diese erscheint auf der Tender-Detail-Seite als Block „KI-Anreicherung" und kann unter Einstellungen → KI-Anreicherungen verwaltet (bearbeiten / löschen / neu generieren) werden. Wenn ein Login für ein Portal in Portal-Logins hinterlegt ist, sieht der Bot auch geschützte Inhalte.

🧠 Tiefe Claude-Analyse

Auf jeder Tender-Detail-Seite gibt es einen Block „Tiefe Analyse (Claude)" mit einem „▶ Mit Claude analysieren"-Button. Claude liest die DB-Daten + die Enricher-Anreicherung + die Admin-Wissensbasis und erzeugt eine strukturierte Bewertung mit fünf Abschnitten:

  • Eckdaten — Auftraggeber, Ort, Frist, geschätzter Wert, Verfahrensart, Ansprechpartner
  • Anhänge / Vergabeunterlagen — Liste der im Material gefundenen PDFs
  • Einsparungspotenzial — konkrete EUR-/Prozent-Schätzung bei Einsatz von Flüssigboden gegenüber klassischer Verfüllung, mit den Annahmen
  • Flüssigboden-Eignung — Bewertung (hoch/mittel/gering/nicht anwendbar) mit Begründung
  • Empfehlung — soll FBE bieten? Falls ja, welcher Hebel

Voraussetzung: ANTHROPIC_API_KEY in der .env auf dem Server gesetzt, Service einmal neu gestartet. Modell wird per ANTHROPIC_MODEL gesteuert (Default: claude-sonnet-4-6). Ergebnis wird gespeichert — beim nächsten Aufruf der Detail-Seite ist es sofort wieder da, ohne API-Kosten.

FAQ

Warum sehe ich keine neuen Treffer?
Prüfe unter 🚦 Status, ob der letzte Lauf fehlerfrei war, und ob das passende Portal aktiviert ist.
Wie kann ich die Suche manuell auslösen?
Über den Knopf „Suche starten“ in der Kopfleiste.
Wo finde ich die API-Dokumentation?
In Einstellungen → API-Dokumentation (öffnet /docs).
