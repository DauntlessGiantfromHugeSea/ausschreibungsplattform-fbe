Was tun mit den Ergebnissen?

  • OK / Treffer > 0 — Portal liefert; nichts zu tun.
  • 0 Treffer (gelb) — Server antwortet, aber Selektor / URL findet keine Karten. Auf 🔍 klicken → Detail-Probe → HTML-Auszug ansehen → Selektor anpassen.
  • Fehler (rot) — meist falsche URL (404), Timeout oder robots.txt-Block. Fehlermeldung lesen, base_url / search_path in /admin/portals korrigieren.
  • deaktiviert — übersprungen. Im UI aktivierbar wenn der Scraper soweit ist.
