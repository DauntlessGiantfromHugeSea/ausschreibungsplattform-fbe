Wartungs-Tools (CLI)

Für seltenere Aufgaben — auf dem Server direkt ausführen:

  • Junk-Einträge bereinigen (Footer/Menü-Müll, der durch zu gierige Parser reingerutscht ist):

python tools/cleanup_junk_tenders.py --archive   # Archivieren
python tools/cleanup_junk_tenders.py --delete    # Löschen

    python tools/dump_portal_html.py
python tools/analyze_dump.py /tmp/portal-debug-extracted
