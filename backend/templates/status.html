Was tun mit den Ergebnissen?

  • OK / Treffer > 0 (grün) — Portal liefert; nichts zu tun.
  • 0 Treffer (gelb) — Server antwortet, aber Selektor / URL findet keine Karten. Auf testen klicken → HTML-Auszug ansehen → Selektor anpassen.
  • Fehler (rot) — meist falsche URL (404), Timeout oder robots.txt-Block. URL in bearbeiten korrigieren.
  • noch nicht (grau) — war im letzten Lauf nicht dabei (neu hinzugefügt oder Lauf vorzeitig abgebrochen).

HTML-Dump aller Portale erzeugen

Wenn ein Portal HTTP 200 mit einigen KB liefert, aber 0 Treffer hat, stimmt der Parser nicht zur tatsächlichen DOM-Struktur. So bekommst du die rohen HTML-Antworten zum Anschauen / Versenden: 

cd /root/ausschreibungsplattform-fbe
source .venv/bin/activate
python tools/dump_portal_html.py
# Erzeugt /tmp/portal-debug.zip mit allen rohen HTML-Antworten
